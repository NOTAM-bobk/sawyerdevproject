# Sawyer Schulz — Personal Site

A clean, Vercel-styled personal site with hand-drawn accents. Built with Next.js (App Router), TypeScript and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Push this repo to GitHub and import it at https://vercel.com/new — Next.js is detected automatically, no configuration required.

## Editing content

All copy (bio, experience, projects, pricing) lives in a single file: [`content/site.ts`](./content/site.ts).
